# 🧩 HUB — платформа «всё в одном»

Универсальный хаб, где живёт всё: чат с агентом, каталог разделов, создание приложений
из идеи, свои ИИ-агенты, база данных, файловый центр со всеми расширениями и упаковка
готовых приложений под любую платформу. Главное здесь — **идея**: пользователь не обязан
уметь программировать, он описывает замысел, а HUB превращает его в работающее приложение.

> Прототип: весь интерфейс и логика — в одном файле `index.html`.
> Открой его двойным кликом в браузере (Chrome рекомендован — там работает голос) —
> ничего устанавливать не нужно, интернет не требуется.

---

## 🚪 Три режима

| Режим | Что это | Зачем |
|---|---|---|
| 💬 **Чат** (по умолчанию) | Агент «Хаб» отвечает на любые вопросы: жизнь, планы, идеи | Обычное общение + входная точка: расскажи идею — получишь план |
| 🧭 **Каталог** («что сделать») | 16 разделов: у каждого шаблона — визуальное превью-окошко + создание по идее прямо внутри | Выбрал раздел → увидел, как выглядит → создал здесь же |
| 🏠 **Хаб** (главное меню) | Мои приложения, рекомендации, статистика, аналитика | Всё созданное живёт здесь: открыть, упаковать, удалить |

## ⌨️ Директивы — команды со слэша

HUB работает со всеми директивами: набери команду в чате (появится автоподсказка)
или скажи голосом «директива каталог»:

| Директива | Действие |
|---|---|
| `/помощь` | весь список директив |
| `/создать [название]` | мастер создания приложения |
| `/шаблоны [раздел]` | шаблоны раздела (музыка, офис, спорт…) |
| `/приложения` · `/открыть <имя>` | список и открытие приложений |
| `/упаковать [имя]` | упаковка приложения |
| `/агент [имя]` | конструктор своего агента |
| `/файл <имя.ext>` · `/файлы` | создать файл любого расширения · файловый центр |
| `/статистика` | метрики платформы |
| `/тема dark\|light\|#цвет` | оформление |
| `/каталог` · `/хаб` · `/очистить` · `/сброс` | навигация и обслуживание |

## 🔄 Ключевой сценарий: «идея → приложение»

1. Пользователь рассказывает агенту идею в чате — например *«хочу сделать голосовой чат»*.
2. Агент включает **план-режим**: раскладывает идею на шаги и показывает ближайший шаблон.
3. Кнопка **«Создать»** → сборка с анимацией (план → интерфейс → логика → база → сборка).
4. Приложение появляется в **Хабе** и **сразу работает** (у каждого шаблона — живой модуль).
5. Кнопка **«Упаковать»** → выбор платформы: 🤖 Android APK · 🪟 Windows EXE · 🐧 Linux AppImage · 🍎 macOS DMG · 📱 iOS IPA · 🌐 Web ZIP.

## 🗂️ Файловый центр — все расширения

Отдельный раздел платформы: HUB работает со всеми типами файлов.

- **Создание**: имя + расширение (подсказки по 50+ форматам) — прямо в центре или командой `/файл отчёт.csv`.
- **Импорт с диска**: текстовые файлы читаются, изображения сохраняются с превью.
- **Просмотр**: текст, код и картинки открываются во встроенном просмотрщике.
- **Экспорт**: скачивание любого файла в один клик.
- **Реестр расширений**: 📄 документы (txt, md, docx, pdf…), 🗃️ данные (json, csv, xml, db…), 🖼️ изображения, 🎵 аудио, 🎬 видео, 💻 код (js, py, java, cpp, html…), 📦 сборки (apk, exe, dmg, ipa, AppImage…).

## 🔤 Реестр «От А до Я · A to Z»

Два реестра приложений мира на двух алфавитах в одном разделе:

- 🇷🇺 **А-Я** — 27 букв, русскоязычные приложения
- 🇬🇧 **A-Z** — 26 букв, англоязычные приложения

Итого **264 записи**: у каждой — иконка, описание, раздел и кнопка «Создать»
(приложение собирается в один клик и сразу работает). Поиск — по текущему алфавиту,
пилюли-буквы прокручивают страницу. Реестр постоянно пополняется.

Кнопки: «Пересобрать картинки», «ИИ-тексты» (по ключу). Экспорт — .html со стилем, картинками
и секциями.

## 🧩 Конструктор приложений — «Доработать» во весь экран

Кнопка **«Доработать»** открывает полноэкранный конструктор (меню чат/каталог скрыто,
пока не нажмёшь «Готово»). Слева библиотека блоков: **метрики** (пользователей сегодня /
за неделю / всего, свои счётчики, часы), списки (задачи, заметки, закладки),
**таблица с поиском, фильтром по каждой колонке и сортировкой кликом**, диаграмма,
дневник с прогрессом, квиз, калькулятор, таймер, текст и сгенерированные картинки.
Каждый блок: тянуй в любое место (⠿), **библиотека блоков всегда слева, свойства
всегда справа** — выбираешь блок и меняешь всё мгновенно, без подтверждений. Старый рантайм приложения остаётся внутри как первый блок —
ничего не теряется. Кнопки: выше/ниже/убрать, колонки 1↔2.

## 🖥️ Студия — полноценная IDE с агентом справа

Вид как в Visual Studio: **слева проводник** (папки и файлы проекта — создать/открыть),
**в центре редактор** с вкладками, номерами строк и Ctrl+S, **справа чат с агентом**.
Файлы хранятся в проекте: README.md, Код/*.js|md, Данные/приложения.json (живой экспорт),
Проект/index.html (просмотр платформы). Агент в чате понимает команды **даже с опечатками**
(«аткрой» → открой, с уточнением) и работает с файлами: newfile Код/app.js, openfile,
rmfile. Команды платформы: create <идея> (соберёт приложение и откроет в конструкторе),
theme, style, stats, backup, search, tour, help. В чате есть **голосовой ввод** 🎙. Для баз данных: файл `База/схема.sql` —
настоящий мини-SQL: CREATE TABLE, INSERT, SELECT с WHERE/ORDER BY/LIMIT, DROP —
кнопка «▶ Выполнить» показывает таблицу результата. Свободный текст — агенту чата,
а с ИИ-ключом — настоящему ИИ.

## 🎮 Обучение — как Duolingo, только про код

Выбери формат: **📖 Читать** — учебник с примерами и запуском кода в песочнице; **🎮 Как Duolingo** —
путь уроков-кружочков, +10 XP за урок, уровни и стрики («🔥 3 дня подряд»); **🧪 Практика** — сразу
задачи с проверкой ответов и подсказками. У каждого урока — фильтры «С примерами» и «С задачами»,
кнопка «Запустить в песочнице» (код урока открывается в HUB-песочнице и выполняется по-настоящему),
и «Спросить Хаба», если что-то непонятно.

## ▶️ Песочница кода — стороннее не нужно

Полноценный редактор JavaScript внутри HUB: запуск одним кликом, перехват console.log, честные
ошибки с объяснением («Переменная не существует — проверь написание…»), а с ИИ-ключом Хаб разбирает
ошибку по-настоящему и объясняет своими словами. Примеры: привет мир, циклы, функции, массивы.

## 🧭 Обзорный тур

При первом входе HUB сам показывает 5-шаговый тур с подсветкой интерфейса:
чат → каталог → хаб → создание → проба. Повтор: кнопка **?** в панели или `/тур`.

## 🤖 Агенты

- **Хаб** 🧠 — основной агент: план-режим, шаблоны, директивы, файлы, помощь по жизни.
- Свои агенты: имя + аватар + приветствие + навыки (планирование, мотивация, код, спорт…).
- Переключение на своего агента — выпадающим списком в чате; пресеты добавляются в один клик.

## 🎙️ Голос

- **Микрофон** в чате — говори запрос голосом (Chrome, Web Speech API), директивы тоже работают: «директива каталог».
- **Кнопка 🔈** — агент озвучивает ответы (синтез речи браузера).

## 🗄️ Данные

Всё хранится локально: приложения, агенты, чат, файлы, статистика, содержимое таблиц
и заметок — в памяти + localStorage. Сброс — кнопкой ↺ в боковой панели или командой `/сброс`.

## 🔍 Поиск везде + бэкап

**Ctrl+K** (или лупа в сайдбаре, или `/поиск трекер`) — мгновенный поиск по всему HUB сразу:
мои приложения, готовые шаблоны, темы обучения и реестр «А-Я · A-Z». Клик по результату —
открывает или создаёт. В настройках — **«Все возможности»** (честный список того, что включено),
**скачивание бэкапа .json** со всем содержимым и **восстановление из файла** — перенос на другой
компьютер за один клик. У каждого приложения с данными — свои наборы-шаблоны (плейлисты,
раскадровки, формулы, датасеты, сцены, техника, презентации, документы, код-примеры): 57 наборов.

## 📦 Настоящие сборки

В папке `dist/` лежит готовый дистрибутив: **hub_1.0_all.deb** (устанавливается в Linux:
`sudo dpkg -i hub_1.0_all.deb` → ярлык в меню, команда `hub`), **HUB-Windows-portable.zip**
(распаковать → HUB.bat) и **HUB-Android-project.zip** (проект APK-обёртки: Android Studio →
Open → Build APK). Плюс сам index.html — PWA: выложи на https и Chrome на телефоне предложит
«Установить приложение» (манифест и иконки вшиты). Кнопки скачивания — прямо в модале
«Упаковать» в HUB.
